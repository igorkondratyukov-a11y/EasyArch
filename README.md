#  EasyArch Linux

**EasyArch** is an Arch-based Linux distro for beginners, delivering a clean, painless, and lightweight KDE Plasma experience out of the box. 

It gives you all the power of Arch Linux without the complexity of a manual command-line installation.

---

##  Features

- **Pure Arch:** No bloatware, no hidden layers, just standard Arch Linux.
- **Lightweight KDE Plasma:** Fast and beautiful interface with only the essential apps pre-installed.
- **Easy Installer:** Modern graphical setup wizard powered by Calamares.

---

##  How to Install EasyArch

### 1. Download the ISO
Go to the **Releases** section on the right side of this page and download the latest `easyarch-xxxx.iso` file.

### 2. Create a Bootable USB
Flash the downloaded ISO file to a USB flash drive (minimum 4GB) using one of these free tools:
- **Ventoy** (Recommended for Linux/Windows)
- **Rufus** (Select "DD Mode" if prompted)
- **BalenaEtcher** (Simple cross-platform tool)

### 3. Boot and Install
1. Plug the USB drive into your PC.
2. Restart your computer and press the boot menu key (usually `F12`, `F11`, `F8`, or `Esc`).
3. Select your USB drive to boot into the **EasyArch Live Session**.
4. Once the desktop loads, double-click the **Install EasyArch** icon on your screen and follow the instructions.

##  Requirements
- **64-bit Processor** (Intel or AMD)
- **2 GB RAM** (4 GB or more recommended)
- **20 GB of free disk space**
- **Internet connection** during installation (to download the latest packages)
